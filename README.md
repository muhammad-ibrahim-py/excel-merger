# Excel Merger

A Python automation tool that merges multiple Excel files into one file using pandas.

## What It Does

- Finds all Excel files in a folder
- Reads each file
- Combines them into one table
- Saves the result as `merged_sales.xlsx`

## Technologies Used

- **Python 3.12+**
- **pandas** for data manipulation
- **pathlib** for file handling
